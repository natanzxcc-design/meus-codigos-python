# Meus Códigos Python 🐍

Este repositório reúne programas e exercícios que desenvolvo durante meu aprendizado de Python e lógica de programação. Meu objetivo é praticar, testar ideias e acompanhar minha evolução como programador.

## 📂 Projetos

### 1. Guarda-chuva ☔

Programa que utiliza a probabilidade de chuva para recomendar se é necessário levar um guarda-chuva.

**Conceitos praticados:** entrada de dados, conversão de valores, estruturas condicionais e validação de informações.

[Ver código](guarda_chuva.py)

### 2. Partida de Basquete 🏀

Simulação interativa de uma partida de basquete entre personagens. O jogador escolhe seus personagens, forma uma dupla e toma decisões durante as jogadas.

**Conceitos praticados:** classes, objetos, métodos, variáveis, cálculos, estruturas condicionais e lógica de jogo.

[Ver código](partida_de_basquete.py)

### 3. Partida de Basquete 2.0 🏀

Uma nova versão da simulação de basquete, com personagens que possuem características diferentes e situações de jogo que influenciam o resultado das jogadas.

**Conceitos praticados:** programação orientada a objetos, classes, métodos, listas, estruturas de repetição, cálculos e uso de módulos.

[Ver código](copy_of_partida_de_basquete_2_0.py)

### 4. Calculadora de Média de Quatro Notas 📊

Programa que recebe quatro notas, calcula a média do aluno e informa se ele foi aprovado ou reprovado de acordo com o resultado.

**Conceitos praticados:** funções, parâmetros, retorno de valores, listas, estruturas de repetição, cálculos e condicionais.

[Ver código](calculo_de_nota.py)

### 5. Calculadora de Média com Quantidade Variável de Notas 🧮

Programa que permite inserir várias notas, armazená-las em uma lista e calcular a média quando o usuário encerra a entrada de dados.

**Conceitos praticados:** listas, estruturas `while` e `for`, tratamento de exceções com `try/except`, funções e cálculos.

[Ver código](calculo_de_nota_2_0.py)

## 🛠️ Tecnologias e ferramentas

- **Python:** linguagem utilizada para desenvolver os programas.
- **Google Colab:** ambiente utilizado para escrever e executar os códigos.
- **GitHub:** plataforma utilizada para armazenar, organizar e apresentar os projetos.

## 🎯 Objetivos de aprendizado

- Aprimorar minha lógica de programação.
- Desenvolver códigos mais organizados e legíveis.
- Aprender a identificar e resolver erros por conta própria.
- Praticar funções, classes, listas e estruturas de repetição.
- Criar programas interativos e projetos relacionados a jogos.
- Registrar minha evolução e construir um portfólio de projetos.

## 📈 Sobre o portfólio

Este repositório representa minha jornada de aprendizado em programação. Os projetos são desenvolvidos utilizando Python e o Google Colab, com o objetivo de colocar em prática os conceitos estudados.

Cada programa representa uma etapa do meu aprendizado, desde exercícios de lógica e cálculos até projetos interativos com personagens e mecânicas de jogo.

Pretendo continuar estudando, aprimorando minhas habilidades e desenvolvendo projetos cada vez mais completos.
